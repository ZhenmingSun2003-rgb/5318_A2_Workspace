# 小组内部 PathMNIST EDA 实验室

这是 COMP5318 A2 小组内部使用的**中文可视化工具**。研究对象是 **28×28 RGB 结直肠组织病理切片 PathMNIST（Canvas 子集）**，不是 A1 的大米形状数据，也不是面向临床使用的诊断系统。

从仓库根目录运行：

\`\`\`bash
conda env create -f requirements.yaml
conda activate comp5318-a2
streamlit run eda_lab/app.py
\`\`\`

应用会自动查找 \`Canvas Sources/Assignment2Data-1/Assignment2Data/\` 四个 NPY 文件；不复制、不修改原始数据。

界面包括：

1. **整体结构与类别**：检查 NHWC 四维结构 \`(样本数, 高, 宽, 通道)\`、dtype、训练类别数及类别不平衡；
2. **样本图库**：分层随机抽样各类图像，观察 H&E 染色下的颜色、细胞密度、空间纹理等表象（视觉解释并不代表病理诊断）；
3. **色彩分布**：RGB 像素直方图、每类平均颜色和标准差，可辅助判断是否有染色或亮度差异；
4. **PCA 二维探索**：只对随机抽取的原始训练图像执行 PCA，不使用测试数据；二维投影丢失信息，类别点云重叠不等同于模型上限；
5. **数据审计**：基础像素范围、缺失/非有限检查及必要边界。

**保护测试集的原则：** 测试集只作最终模型比较。界面默认不展示测试内容的图形；只有手动启用检查开关时，才显示测试集的结构与标签数量（便于核对文件）。请勿通过分析测试集设计预处理、选择模型或调参。

**资源与性能**：界面采用 mmap 读取原数组、用缓存和限制采样规模进行统计与降维；在较大的数组上，首次读取或生成图表仍需要一些内存。请在 Streamlit 启动输出里确认访问地址；退出可用 Ctrl+C。

**类别来源**：https://github.com/MedMNIST/MedMNIST/blob/main/medmnist/info.py 。对应 0–8 的官方类名，如文件实际标签不同，工具会显示未映射的类别 ID。课程给定子集的样本数和标签比例由实际 NPY 读取，不沿用官网整套数据的数量。

**局限**：NPY 中未包含患者、医院、染色协议等信息，不能凭颜色差异推断来源，也不能验证患者级别的数据独立性。数据仅用于学习及报告讨论，非诊断用途。
